The Relationship between GameObjects, Components, and Scripts

A GameObject is container for an object, where you are able to use components to give each game object different features. It represents characters, props, lights, and cameras, but they do nothing on their own without components. Components are built-in or custom classes attached to a GameObject to add specific features (like physics!) A script is a piece of code that tells the GameObject how to behave and a set of actions.
